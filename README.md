## 🚀 Featured Projects

### 🐝 HiveGuard AI
**IoT Beehive Acoustic Health Monitoring**

Multidisciplinary IoT project monitoring beehive health via acoustic sensing — ESP32 + INMP441 mic with propolis protection, DHT22 sensor, solar + 18650 power, deep-sleep duty cycling. Multimodal contrastive baseline-adaptive risk scoring validated on the BeeTogether dataset. Delivered as an IEEE conference paper with a provisional patent application.

**Focus:** IoT • Machine Learning • Embedded Systems

---

### 🎯 PrepPilot
**AI Placement Prep Platform** — built for the Agentverse Grand Challenge Hackathon

React + Vite frontend, Node.js/Express backend, SQLite, Firebase Authentication, and 9 AI agents on Groq/Llama 3.3 70B covering MCQ generation, mock interviews, coding challenges (via Judge0), resume ATS scoring, and LeetCode integration.

**Focus:** Full-Stack Development • AI Agents • EdTech

---

### 🛡️ EdgeGuard AI
**Real-Time Industrial Safety System** — built for the Tata InnoVent hackathon

Edge-deployed safety monitoring using YOLOv8-nano and ByteTrack for PPE compliance and danger-zone intrusion detection, with a web dashboard, running fully offline on-edge.

**Focus:** Computer Vision • Edge AI • Industrial Safety

---

### 🎥 Face Recognition Attendance System
**Cloud-Deployed Attendance Platform**

A cloud-based attendance system using face recognition, with an analytics dashboard for attendance trends, late-arrival patterns, and monthly summary graphs.

**Focus:** Computer Vision • Cloud Deployment • Analytics

### 🔐 TechnIQ Vision — Fraud Detection Tool
